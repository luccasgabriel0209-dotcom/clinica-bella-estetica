# Clínica Bella Estética

Landing page estática da Clínica Bella Estética | Dra. Eliana Andrade, com foco em contato pelo WhatsApp. Abra `index.html` no navegador ou sirva a pasta com um servidor estático. Não há build nem backend.

## Editar

- Textos, serviços, endereço e links: `index.html`.
- Cores, layout e imagens: `styles.css`.
- Número e mensagens do WhatsApp: `script.js`.

As fotografias externas do Unsplash são **ilustrativas** e não representam a Dra. Eliana, clientes ou o espaço real. Substitua pelas fotos autorizadas da clínica antes de divulgar a página como apresentação visual do local. A nota e a contagem de avaliações vieram do briefing; confirme se continuam atuais antes de publicar. Horários são indicados como consulta pelo WhatsApp porque não foram informados.

O site ainda não está hospedado. Publicar este repositório no GitHub não ativa automaticamente o GitHub Pages.
